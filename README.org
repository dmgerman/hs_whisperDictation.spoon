#+title: WhisperDictation - Voice to Text for Mac
#+author: Daniel M. German
#+date: 2026

Speak and see your words appear as text. Works offline, supports 100+ languages, and puts privacy first.

* ⚠️ Version 2.0 - Rearchitected

*This version has been completely rearchitected* for better reliability and maintainability:
- New callback-based architecture (simpler, more testable)
- Improved error handling and state management
- Post-transcription filters (pipe text through shell commands or LLMs)
- 600+ comprehensive tests

*Breaking changes from v1.x:*
- Configuration API changed (see examples below)
- =recordingBackend= → =config.recorder=
- =transcriptionMethod= → =config.transcriber=
- =pythonstream= → =streaming=

If upgrading from v1.x, you'll need to update your configuration.

* What Does It Do?

1. *Press a hotkey* to start recording
2. *Speak* your text
3. *Press the hotkey again* to stop
4. *Get your text* - either pasted automatically or copied to clipboard
5. Optionally, *apply a filter* (e.g., grammar fix, translation, LLM query) before the text reaches clipboard

* Quick Start

#+begin_src lua

  transcriber = "whisperkit", -- Apple optimized, local

1. Press your toggle hotkey
2. A sound wave overlay appears on screen while recording
3. Speak: "Hello world, this is a test"

* Features

** Copy to Clipboard (Default)

Press hotkey → Speak → Press hotkey → Paste (Cmd+V).

** Auto-Paste

Text automatically pastes if you don't type/click during recording.

#+begin_src lua
wd.monitorUserActivity = true

wd:bindHotKeys({
  toggle = {{"ctrl", "cmd"}, "d"},      -- Copy mode
  togglePaste = {{"ctrl", "cmd"}, "p"}, -- Auto-paste mode
})
#+end_src

*Auto-pastes when:* you stayed in the same app, didn't type, didn't click.

*Copies to clipboard instead when:* you typed, clicked, or switched apps.

** Multiple Languages

#+begin_src lua
wd.languages = {"en", "ja", "es"}

wd:bindHotKeys({
  toggle = {{"ctrl", "cmd"}, "d"},
  nextLang = {{"ctrl", "cmd"}, "l"},
})
#+end_src

Press the =nextLang= hotkey to open a chooser and switch languages.

** Retranscription

Re-transcribe a previous recording with a different transcriber or language.

#+begin_src lua
wd:bindHotKeys({
  toggle = {{"ctrl", "cmd"}, "d"},
  retranscribe = {{"ctrl", "cmd"}, "r"},
})

-- Optional: use a specific transcriber for retranscription
wd.retranscribeTranscriber = "whisperkit"  -- or nil to use current
wd.retranscribeCount = 15  -- recent recordings shown (default: 10)
#+end_src

Press the =retranscribe= hotkey, pick a recent recording from the chooser, and it will be retranscribed with the current language.

** Abort

Cancel the current recording or transcription and return to idle.

#+begin_src lua
wd:bindHotKeys({
  toggle = {{"ctrl", "cmd"}, "d"},
  abort = {{"ctrl", "cmd"}, "a"},
})
#+end_src

Works from any state:
- *While recording:* stops the recorder and discards the audio
- *While transcribing:* cancels pending transcriptions
- *While idle:* does nothing

** Custom Callback

Instead of clipboard, do whatever you want with the text:

#+begin_src lua
wd:toggleTranscribe(function(text)
  print("You said: " .. text)
  -- Save to file, post to webhook, send to app, etc.
end)
#+end_src

* Post-Transcription Filters

Pipe your transcription through any shell command before it goes to clipboard. Filters read from stdin and write to stdout.

** Basic Usage

#+begin_src lua
wd.whisperFilters = {
  { name = "Fix Grammar", abbrev = "CLN", cmd = "grammar-fix" },
  { name = "Translate to Spanish", cmd = "translate-es" },
}

wd:bindHotKeys({
  toggle = {{"ctrl", "cmd"}, "d"},
  selectFilter = {{"ctrl", "cmd"}, "f"},
})
#+end_src

Press the =selectFilter= hotkey to open the filter chooser. The selected filter stays active for all subsequent recordings until you change it. Choose "No Filter" to return to raw transcription.

When a filter with an =abbrev= is active, the abbreviation is shown in the menubar and recording alerts (e.g., =🎤 (en) [CLN]=).

** How It Works

1. Record and transcribe as normal
2. If a filter is active, the transcribed text is piped through the filter command
3. The filtered output replaces the original text in the clipboard
4. If the filter fails, the original unfiltered text is used instead and a warning is shown

** Filter Configuration

#+begin_src lua
wd.whisperFilters = {
  { name = "Display Name", abbrev = "DN", cmd = "shell-command-here" },
  { name = "Another Filter", cmd = "other-command" },
}
#+end_src

Fields:
- =name= (required) — Display name in the chooser
- =cmd= (required) — Shell command that reads stdin and writes to stdout
- =abbrev= (optional) — Short label shown in menubar and alerts (e.g., "CLN", "GPT"). If omitted, no indicator is shown.

The command runs in a login shell (=/bin/zsh -l=) so your full PATH is available.

** Writing a Filter Script

A filter is any command that reads stdin and writes to stdout:

#+begin_src bash
#!/bin/bash
# Simple: uppercase everything
tr '[:lower:]' '[:upper:]'
#+end_src

#+begin_src python
#!/usr/bin/env python3
import sys
text = sys.stdin.read()
# ... process text ...
print(corrected_text)
#+end_src

** Error Handling

- *Script not found:* original text is used, warning alert shown
- *Non-zero exit code:* original text is used, warning alert shown with stderr
- *Empty output:* original text is used
- *Script hangs:* original text will eventually be used (no timeout currently)

** Included Script: query-model.py

The spoon ships with =scripts/query-model.py=, a versatile LLM query tool that works as a filter. It auto-detects available backends (local LM Studio or ChatGPT) and supports three modes:

| Mode     | Description                        |
|----------+------------------------------------|
| =answer= | Answer a question succinctly       |
| =filter= | Apply a custom prompt to the input |
| =raw=    | Send input as-is to the LLM       |

*Requirements:* =pip install requests=, and either a local LLM (e.g., LM Studio on port 1234) or an OpenAI API key stored in =~/.authinfo.gpg=.

*Example filter configuration:*

#+begin_src lua
-- Use the spoon's bundled script
local spoonPath = hs.spoons.resourcePath("hs_whisperDictation")
local qm = spoonPath .. "/scripts/query-model.py"

wd.whisperFilters = {
  { name = "Clean grammar", abbrev = "CLN",
    cmd = qm .. " filter -p 'Correct the grammar, only respond with the corrected text'" },
  { name = "Answer question", abbrev = "ANS",
    cmd = qm .. " answer" },
  { name = "Make checklist", abbrev = "LST",
    cmd = qm .. " filter -p 'Format as an org-mode checklist'" },
}
#+end_src

*Backend selection:*

#+begin_src bash
# Auto-detect (tries local first, then ChatGPT)
scripts/query-model.py answer "What is Lua?"

# Force local LLM only
scripts/query-model.py --backend local answer "What is Lua?"

# Force ChatGPT
scripts/query-model.py --backend chatgpt filter -p "Translate to Spanish"
#+end_src

Run =scripts/query-model.py --help= for full usage.

* Transcription Methods

| Method          | What it is                       | Speed     | Privacy    | Best for                     |
|-----------------+----------------------------------+-----------+------------+------------------------------|
| =whisperkit=    | Apple Neural Engine on your Mac  | ⚡⚡ Fast | 100% local | Apple Silicon Mac users      |
| =whispercli=    | Whisper on CPU/GPU               | ⚡ Slower | 100% local | Non-Apple Silicon Macs       |
| =whisperserver= | Local HTTP server (model in RAM) | ⚡⚡ Fast | 100% local | Heavy users (model stays loaded) |

** whisperkit (Apple Silicon - Recommended)

Uses Apple's Neural Engine. 100% local, nothing leaves your Mac.

#+begin_src bash

#+end_src

#+begin_src lua

  transcriber = "whisperkit",
}
#+end_src

|-------------+-------------------------------------+---------------------------------|
| =sox=       | Records one file per session        | Simple needs, reliable          |
| =streaming= | Real-time with smart chunking (VAD) | Long dictations, faster results |

** sox (Simple - Recommended)

Records one audio file per session. Reliable and straightforward.

#+begin_src bash

#+end_src

#+begin_src lua

  recorder = "sox",
}
#+end_src

** streaming (Smart - Beta)

Real-time recording with intelligent silence detection (Silero VAD). Creates chunks automatically and transcribes while you're still talking. The Python server pre-starts at initialization so the first recording starts instantly.

#+begin_src bash
pip install sounddevice scipy torch
#+end_src

#+begin_src lua
wd.config = {
  recorder = "streaming",
  streaming = {
    silenceThreshold = 2.0,   -- Seconds of silence before chunk split
    minChunkDuration = 3.0,   -- Minimum chunk length (seconds)
    maxChunkDuration = 600.0, -- Maximum chunk length (seconds)
  },
}
#+end_src

*Note:* Streaming is in beta. Use =sox= if you want maximum reliability.

* Troubleshooting

** "No audio recorded"

1. Check microphone permissions: System Settings → Privacy & Security → Microphone → Enable Hammerspoon
2. Check microphone selection: System Settings → Sound → Input → Choose your mic
3. Test recording: =sox -d test.wav= (speak for 5 seconds, Ctrl+C), then =afplay test.wav=

** "Empty transcription"

1. Verify audio file: =ls -lh /tmp/whisper_dict/*.wav= (should be >100KB)
2. Play recording: =afplay /tmp/whisper_dict/en-*.wav | tail -1=
3. If silent, check microphone in System Settings

** "Streaming server won't start"

#+begin_src bash
lsof -i :12341                              # Check if port is in use
lsof -ti:12341 | xargs kill -9              # Kill zombie process
pip list | grep -E "sounddevice|torch|scipy" # Check Python deps
#+end_src

** "Whisper command not found"

#+begin_src bash
brew install whisperkit-cli  # For WhisperKit
brew install whisper-cli     # For WhisperCLI
brew install sox             # For Sox recorder
#+end_src

** Debugging in Hammerspoon Console

#+begin_src lua
-- Open console: Cmd+Opt+Ctrl+C

-- Check current status
print(hs.inspect(wd:getStatus()))

-- List recent recordings
print(hs.execute("ls -lht /tmp/whisper_dict/*.wav | head -5"))

-- Play most recent recording
latest = hs.execute("ls -t /tmp/whisper_dict/*.wav | head -1"):gsub("\n", "")
hs.execute("afplay " .. latest)
#+end_src

* Privacy & Security

*Everything stays on your Mac:*
- All configurations, recordings, and transcriptions are 100% local
- No telemetry, no tracking, no cloud services

*Note on filters:* If you configure a filter that calls an external API (e.g., ChatGPT via =query-model.py --backend chatgpt=), your transcribed text will be sent to that service. Use =--backend local= or local-only filters to keep everything private.

*To maximize privacy:*
- Use =whisperkit= or =whispercli= for transcription (100% local)
- Use filters that run locally (e.g., =--backend local= with LM Studio)
- Audio files are never sent anywhere — only transcribed text can be sent to filters
